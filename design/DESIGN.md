# DESIGN.md · AEL 设计系统

> 导入 Stitch 用于统一视觉。也作为前端 Tailwind 主题的依据。

## 产品调性
开发者工具。克制、清晰、信息密度适中。参考 Linear / Raycast / Vercel Dashboard。
不花哨,不用渐变和重阴影。让数据和状态一眼可读。

## 颜色

浅色模式为主,支持深色。

```
背景        #FFFFFF / 次级面 #F6F6F4 / 页面底 #F1EFE8
主文字      #1F1F1D   次文字 #6B6A64   提示 #9C9A92
边框        rgba(0,0,0,0.10)  强调边框 rgba(0,0,0,0.18)
主色(品牌)  #534AB7  (靛紫,用于主按钮、选中态、链接)
```

语义色（用于状态徽章和证据链事件)
```
进行中 in_progress   蓝  #185FA5 / 底 #E6F1FB
已验证 verified      绿  #3B6D11 / 底 #EAF3DE
受阻   blocked       琥珀 #BA7517 / 底 #FAEEDA
失败   failed        红  #A32D2D / 底 #FCEBEB
待办   pending       灰  #5F5E5A / 底 #F1EFE8
错误事件 error        红
修复事件 fix          绿
决策事件 decision     紫  #534AB7
```

状态徽章/标签上的文字,用同色系的深色,不要用纯黑。

## 字体
- 界面:系统无衬线(Inter / -apple-system / Segoe UI)。
- 代码 / 日志 / 错误输出:等宽(SF Mono / Consolas / monospace)。
- 字号:正文 14、次要 12、小标题 16、标题 18-22。字重只用 400 与 500。
- 全部句首大写,不用全大写、不用标题式 Title Case。

## 间距与圆角
- 间距用 4 的倍数(4 / 8 / 12 / 16 / 24)。
- 圆角:卡片 12,控件 8,徽章/胶囊用半高。
- 边框统一细线(0.5–1px)。

## 组件规范
- **按钮**:主按钮填主色白字;次按钮描边透明底,hover 加浅底。
- **卡片**:白底 + 细边框 + 12 圆角 + 16 内边距。
- **状态徽章**:小胶囊,语义底色 + 同色深字。
- **证据链时间线**:左侧竖线 + 节点,节点颜色按事件类型;每条一行摘要,可展开详情(详情里日志用等宽)。
- **空状态**:友好的一句话 + 一个主操作按钮。

## 可访问性
- 不只靠颜色区分状态——同时配图标或文字。
- 正文对比度达 AA。
- 可键盘操作主流程。
