# 界面规格 · screens.md

供 Stitch 出图、Antigravity 实现共同参照。窗口 1100×720,左侧固定导航 + 右侧主区。

## 全局布局
- 左侧导航(约 200px):Logo「AEL」/ 任务 / Skill 库 / 失败模式 / 设置。
- 主区顶栏:面包屑/标题 + 搜索框 + 主操作按钮。

## 1. 任务列表(默认页)
- 主区:任务卡片纵向列表。
- 卡片:标题、目标摘要(1-2 行截断)、状态徽章、agent 标识、更新时间、标签。
- 顶栏:搜索、状态筛选、「新建任务」。
- 空状态:"还没有任务,新建一个开始记录。"

## 2. 单任务详情(核心)
- 头部:标题 + 状态徽章 + agent + 标签;操作:改状态、导出接手包。
- 主体「证据链」:竖向时间线,节点按类型着色(step/error/fix/verification/decision)。
  - 每条:类型图标 + 时间 + 一句话摘要,点击展开详情(日志/diff 用等宽字体,可复制),证据链接可点。
  - 底部输入区:快速追加一条事件(选类型 + 写摘要 + 可选详情/证据)。
- 侧栏:本任务沉淀的 Skill(draft 待确认)、相关失败模式。

## 3. Skill 库
- 卡片网格(每行 2-3 张)。
- 卡片:名字、trigger(何时适用)、状态徽章(draft/active/deprecated)、成功/失败计数、标签。
- 顶栏:按状态筛选 + 搜索。
- 点开抽屉:看 body(markdown 渲染)、改状态、看来源任务。

## 4. 失败模式 / Failure Guard
- 列表:描述、错误签名(等宽显示)、出现次数、修复方法、guard 约束。
- 顶部说明条:"以下坑会在相似任务开始时自动提醒 Agent。"
- 点开看完整 root_cause / fix / guard_rule。

## 5. 接手包导出弹窗(modal)
- 勾选包含项:证据链 / 相关 Skill / 相关失败 / 未决问题(可加自定义未决问题)。
- 中部:实时预览「接手 Prompt」文本。
- 底部:取消 / 导出 handover.zip。
- 导出后提示文件路径,并提供「复制接手 Prompt」按钮。

## 交互约定
- 新建任务后直接进详情页。
- finalize 任务 → 弹出 draft Skill/Failure 让用户确认(active)或丢弃。
- 进入一个新任务详情时,若 Failure Guard 命中,顶部显示一条提醒带约束清单。
