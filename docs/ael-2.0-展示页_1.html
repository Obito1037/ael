出口 ③运行时海关 · POLICY GATE

但不会被网关遗忘

写进 prompt 的安全规则,在长任务后半段会被模型丢掉。所以裁决必须发生在模型之外—— AEL 的 PTY 恰好坐在 Agent 和 Shell 之间。点击开始巡检,看每条命令过关: 危险命令会被扣在裁决线上,由你放行或拦截(不处理则默认拦截)。

出口 ①REVIEW BRIEF · 证据编译

出口 ②AGENT BLAME · 行级溯源

git blame 追到人,
AEL 追到决策现场

信任危机的根源是责任无法归位。AEL 把 task_id 写进 commit trailer、证据链按行锚定—— 悬停或点击左侧任意一行代码,右侧立即回放它的来历:哪次任务、哪个模型、 基于哪条决策、谁在什么时候确认。事故复盘时,「AI 建议错了」和「人确认错了」一目了然。
