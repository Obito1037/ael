# 记忆学习与复用：可交互演示

## 入口

桌面侧栏点击 **体验记忆复用**，或从首页“先体验一次记忆学习与复用”进入。浏览器预览也支持 `/#demo` 直接进入。

演示状态只保存在当前窗口的独立内存中。切换页面后可以继续；刷新或关闭窗口会重置。所有案例、检查与记录明确标记为模拟，不调用模型、不执行系统命令，也不写入真实任务、Skill 或 Failure。

## 推荐展示顺序

1. 观察第一次 Windows 路径错误。
2. 选择“保留路径，用参数数组传递”，运行模拟样例验证；可先选错误方案展示失败与恢复。
3. 从通过的样例证据中提炼记忆候选，展开记忆卡查看适用条件与来源。
4. 人工审阅并启用。
5. 为下一个相关任务检查召回，选择复用。
6. 应用记忆后，独立验证本次模拟结果，再提交有帮助或负面反馈。
7. 查看本次记录，下载带 `simulation: true` 的 JSON，或复制 Markdown 记录。

## 可操作的反例

- **错误修复**：删除空格或写死路径会改变目标目录；模拟验证失败时不能提炼可靠候选。
- **未经确认**：在候选阶段尝试召回，会显示未确认的阻挡原因。
- **不相关任务**：切换为“调整登录页配色”，路径构建经验不参与召回。
- **环境变化**：切换为 Linux 构建；直接信任旧 Windows 结果无法通过重验，需检查新环境路径。
- **不使用记忆**：重新选择修复方案并验证，过程与复用分支分别记录，不预设效率提升数字。
- **负面反馈**：记忆暂停召回；恢复后保留负面记录，不把错误历史抹掉。
- **重置**：只清空演示状态，真实工作空间不变。
